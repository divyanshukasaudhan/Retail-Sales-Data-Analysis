# 📊 Retail Sales Data Analysis | Excel & Power Query

## 📌 Project Overview

This project focuses on analyzing retail sales data using **Microsoft Excel, Power Query, Pivot Tables, and Interactive Dashboards**.

The objective is to evaluate sales performance, identify profitable products, analyze regional revenue, and generate actionable business insights to support data-driven decision-making.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Pivot Tables & Pivot Charts
- Excel Formulas
- Data Cleaning & Transformation
- Data Visualization
- Interactive Dashboard

## 📂 Dataset Description

The project includes the following datasets:

- January Sales Data
- February Sales Data
- March Sales Data
- Customer Master Data
- Product Master Data

**Total Records Analyzed:** 4,500 Sales Records

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning using Power Query
3. Append Monthly Sales Data
4. Merge Customer and Product Master Data
5. Data Transformation
6. Calculate Sales, Cost and Profit
7. Create Pivot Tables for Analysis
8. Develop Interactive Excel Dashboard
9. Generate Business Insights and Recommendations

## 💡 Key Business Insights

- **Monthly Performance:** February generated the highest monthly sales.
- **Regional Performance:** Noida was the highest revenue-generating region.
- **Category Performance:** Home & Kitchen was the top revenue-generating category.
- **Product Performance:** Fashion Product 21 generated the highest revenue.

## 📊 Dashboard Features

The interactive Excel dashboard includes:



- Monthly Sales and Profit Analysis
- Region-wise Sales Performance
- Category-wise Sales Analysis
- Top Products Analysis
- City Filters
- Date Filters
- Customer Segment Filters

## 🎯 Business Recommendations

1. Focus on high-performing and profitable products.
2. Improve inventory management based on sales trends.
3. Analyze the strategies of high-performing regions.
4. Identify opportunities to improve low-performing categories.
5. Maintain data quality and accuracy for better business decisions.
